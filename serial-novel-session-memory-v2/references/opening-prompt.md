# 快速启动指令 v2.0

---

## 一、新作品开场

把以下指令作为会话第一条消息，随后直接附上设定与第 1 章任务即可开写。

```
【按 serial-novel-session-memory v2.0 协议创作】

分段声明: [第一卷: 第1–X章] [第二卷: 第X–Y章] …（如未声明，默认每5章生成标准快照）

————————————————
[在此粘贴你的设定：世界观 / 人物 / 文风]
————————————————

第1章「标题」
剧情目标: ……
伏笔事件: ……
字数: ……
```

### 首章回复

模型返回三部分：
- `【第1章正文】`
- `【本章小结与台账变更】`
- `【轻量快照 v1.0｜第1章】`（初始快照，含状态+伏笔变更）

---

## 二、段内续写（第 2 章起）

### 有文件环境（推荐）

段内不换会话，AI 从上一轮对话历史中的轻量快照自动获取状态——无需粘贴快照：

```
第N章「标题」
剧情目标: ……
伏笔事件: [取自上一章轻量快照的伏笔变更行]
字数: ……
```

（文件落盘是给你的归档备份，AI 从对话历史读取——不是从文件读。）

### 纯会话环境

同上——段内不换会话，上一轮消息中的轻量快照在对话历史中，AI 自动引用。你不需要粘贴轻量快照回传。

**唯一需要手动粘贴快照的场景：换会话。** 此时粘贴标准快照或卷末快照。

### 段内回复

模型返回三部分：
- `【本章正文】`
- `【本章小结与台账变更】`
- `【轻量快照】`（覆盖更新，段内始终只存最新 1 份）

在纯会话环境中，轻量快照随 AI 回复进入对话历史——你下一轮**不需要**粘贴回传，AI 会从上一轮消息中自动读取。换会话时才需要粘贴标准快照。有文件环境同理，文件归档是给你的备份，AI 从对话历史读取。

## 三、段末回复与换会话

### 段末回复（四部分）

```
【第N章正文】
【本章小结与台账变更】
【标准快照 vX.X·完整版｜截至第N章】
[完整快照，可直接复制]

【轻量快照归档提示】
→ 轻量快照已归档至: 快照/light-vX.X-归档.md (如有文件能力)
→ 纯会话环境: 请自行保存上方快照为 .md 文件

【换会话提示】
→ 本段结束，请开新会话，粘贴上方标准快照。
→ 新会话首条: "按 v2.0 协议继续，记忆截至第 N 章" + 标准快照
```

### 换会话 · 有文件环境

开新会话 → 首条消息：

```
按 serial-novel-session-memory v2.0 协议继续，记忆截至第 N 章。
快照文件: 快照/standard-v2.0-截至第15章.md
第N+1章「标题」……
```

AI 读取快照文件 → 冷启动完成。

### 换会话 · 纯会话环境

开新会话 → 首条消息：

```
按 serial-novel-session-memory v2.0 协议继续，记忆截至第 N 章。

【记忆快照 vX.X｜截至第N章】
[粘贴完整快照]

第N+1章「标题」……
```

## 四、卷末回复与跨卷交接

### 卷末回复（六部分）

```
【第N章正文】
【本章小结与台账变更】
【卷末快照 vX.X·完整版｜第X卷完】
（标准快照四段 + 全量伏笔对账 + 跨卷移交清单，三者合一）

【作者伏笔决策请求】
请确认以下伏笔处置方案：
1. V-001: 移交卷2 → 期限顺延为卷2第8章 → 同意/调整?
2. V-005: 移交卷2 → 期限顺延为卷2第15章 → 同意/调整?
3. V-004: 建议本卷回收 → 下章安排? 还是移交?

【轻量快照归档提示】→ 轻量快照已归档至文件（如有文件能力）

【换会话提示】
→ 本卷结束。确认伏笔处置方案后，开新会话粘贴卷末快照继续卷2。
```

> **注意**：卷末快照已包含全量伏笔对账与跨卷移交清单，AI 不会额外再出一份独立的标准快照——卷末和段末互斥。

### 跨卷换会话

```
按 serial-novel-session-memory v2.0 协议继续，记忆截至第 N 章（第一卷完）。
伏笔处置: V-001顺延卷2第8章 / V-005顺延卷2第15章 / V-004下章回收
快照文件: 快照/volume-v1.0-第一卷完.md

第2卷第1章「标题」……
```

## 五、从文件恢复（v2.0 新增）

### 有文件能力的环境

如果已有一系列快照文件，只需告诉 AI 文件路径：

```
按 serial-novel-session-memory v2.0 协议恢复创作。
快照文件: [粘贴完整路径]
```

AI 读取文件 → 解析快照 → 问你想从第几章继续。

### 纯会话环境

从你保存的 `.md` 文件中复制完整快照内容，粘贴到新会话首条消息：

```
按 serial-novel-session-memory v2.0 协议恢复创作。

[粘贴快照文件全部内容]

继续第N+1章「标题」……
```

## 六、双轨保存指引

### 如果你在有文件工具的环境（豆包桌面端 / DSH / Cursor）

AI 会在生成快照时自动写文件——你只需确认文件路径是否正确。建议在项目根目录建 `快照/` 文件夹。

### 如果你在纯 Web 聊天环境

每次看到快照输出 → 复制整个代码块 → 保存为本地 `.md` 文件：

- 轻量快照（归档用）：`快照/light-v1.12-归档.md`
- 标准快照（换会话用）：`快照/standard-v2.0-截至第15章.md`
- 卷末快照（存档用）：`快照/volume-v1.0-第一卷完.md`

### 文件命名建议

```
项目根目录/
└── 快照/
    ├── light-v1.1-归档.md       ← 段内轻量快照归档（每段 1 份）
    ├── standard-v1.0-截至第5章.md
    ├── standard-v2.0-截至第10章.md
    ├── standard-v3.0-截至第15章.md
    ├── volume-v1.0-第一卷完.md
    └── volume-v2.0-第二卷完.md
```
