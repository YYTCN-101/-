# 三级快照：完整模板、预算与压缩规则

---

## 一、轻量快照（每章，≤400 token）

### 用途
段内每章衔接，下一章写前快速对齐当前状态。段内始终只存最新 1 份，覆盖式更新；段末归档到文件，不进入后续上下文。

### 模板

```
【轻量快照 vX.X｜第N章】
【状态变更】
苏晚|萧府西苑→后院|伤愈,玉佩入袖 ｜ 萧玦|书房|查阅密信 ｜ 新增角色: 沈七(暗卫,跟随萧玦)
【伏笔变更】
新增 V-005（后院枯井井壁刻"甲子年",关联苏晚/萧家旧址）｜
推进 V-001（玉佩遇血泛光,呼应章N,未回收）｜
回收 V-003（沈七口中"十年前那晚",关联萧母案,收于N）
```

### 预算控制（≤400 token）

| 子字段 | 预算 | 说明 |
|---|---|---|
| 状态变更 | 200 | 仅列出本章**有变化**的角色/位置/状态；未变的不列 |
| 伏笔变更 | 200 | 新增/回收/推进各一行；"推进"只写呼应章号不重复伏笔全文 |

### 压缩规则

- **覆盖非累积**：每次生成新轻量快照时，旧轻量快照被覆盖——上下文内始终只有 1 份
- 状态字段只写变更项——无变化的不写（"苏晚仍在前院"不列）
- 伏笔推进只给章号和一句定位——不重复伏笔全文（全文在台账中）

## 二、标准快照（段末，≤1200 token）

### 用途
段末生成，换会话时粘贴到新会话作为冷启动记忆源。本段最后一章与前几章的衔接桥。

### 完整模板

```
【记忆快照 vX.X｜截至第N章】
【圣经·压缩】
架空古风悬疑 ｜ 主角: 苏晚(17,寄居萧府,外柔内韧,失忆)、萧玦(20,萧府少主,冷峻,暗中查母案) ｜
配角: 沈七(暗卫)、老仆刘婆(知情人)、掌柜钱三(账房) ｜
第三人称有限视角(苏晚),克制白描,对话含蓄

【状态】
苏晚|萧府后院|伤愈,玉佩贴身,开始怀疑身世|与萧玦互知身份(未挑明)
萧玦|书房|手握密信,调查加速|第12日/深秋/夜
沈七|暗处|跟踪钱三
当前线索: 玉佩-枯井-十年前-萧母案四者已关联

　　【关键事实·不可压缩】
　　已死亡: 无
　　当前境界: 凡人(无修炼体系)
　　关键物品: 玉佩(苏晚贴身)｜密信(萧玦手中)｜枯井刻字(后院,已被发现)
　　不可逆事件: 苏晚已与萧玦联手｜枯井被发现(萧府上下已知)
　　关系锚点: 苏晚↔萧玦: 同盟,互知身份未挑明｜苏晚↔老仆: 敌对,老仆隐瞒关键信息

【摘要链】
第N-4章: …(阶段摘要)…
第N-2章: 苏晚袖中玉佩遇血泛光,老仆失言"十岁那年"(埋V-002);钩子:谁抹掉记忆?
第N-1章: 萧玦夜探账房发现算盘缺子,钱三支吾;钩子:账本被谁动了?
第N章: 沈七在后院枯井发现刻字"甲子年",苏晚心悸;钩子:枯井与玉佩同源?

【伏笔日历】
V-001 最迟18章回收(埋3,可提前) ｜ V-002 最迟25章回收(埋7,可提前) ｜
V-003 已收@10 ｜ V-004 最迟15章回收(埋8,距期限≤2⚠️) ｜
V-005 最迟30章回收(埋N,新埋)

【伏笔台账】
未回收:
V-001｜03｜玉佩遇血泛光,光中隐现符文｜苏晚/玉佩/萧家血脉｜最迟18｜未回收｜最近呼应N
V-002｜07｜老仆失言"十岁那年的事别提"｜苏晚/老仆/失忆真相｜最迟25｜未回收｜最近呼应7
V-004｜08｜钱三偷偷烧掉一页账本｜钱三/账房/萧母案｜最迟15｜未回收⚠️距期限≤2｜最近呼应10
V-005｜N｜后院枯井井壁刻"甲子年"｜苏晚/枯井/萧家旧址｜最迟30｜新埋｜N
已回收:
V-003｜05｜沈七夜巡发现密道,通往城外｜沈七/萧府密道｜已收@10
```

### 分项预算（≤1200 token）

| 字段 | 预算 | 压缩优先级 |
|---|---|---|
| 圣经·压缩 | 250 | ② 超出时精简人物卡（只留核心角色），保留世界观/文风核心 |
| 状态（含关键事实） | 250 | ③ 关键事实不压缩，其余只保留有变化或即将起作用的字段 |
| 摘要链 | 450 | ① **最先压缩**：超出时合并更早章节为阶段摘要 |
| 伏笔日历+台账 | 250 | **不压缩**：伏笔条目内容永不删除/改写 |

### 压缩规则

1. **摘要链先压**：超过 450 token 时，把最早 2–3 条合并为「第 X–Y 章阶段：关键事件摘要」，只保留"关键动作 + 悬而未决的承诺"
2. **承诺类细节不压缩**：伏笔内容、专有名词、人物关系变动、关键物品——压缩时原样保留
3. **台账永不压缩**：伏笔台账条目内容不得删除或改写，只更新"状态 / 最近呼应章"字段
4. **关键事实锚定**：`【关键事实·不可压缩】` 作为状态档案的子字段，与状态同进退——二者必须一致（不另建独立段，避免双份数据分歧）
5. **版本号递增**：每份新标准快照版本号 +0.1

## 三、卷末快照（卷末，目标 2000 token）

### 用途
卷末存档，跨卷长期回溯。在标准快照基础上增加全量伏笔对账和跨卷移交清单。

### 完整模板

```
【卷末快照 vX.X｜第一卷完·截至第N章】
【圣经·压缩】
（同标准快照格式，可酌情扩展至 350 token）

【状态】
（同标准快照格式，含关键事实，可酌情扩展至 300 token）

【摘要链】
第一卷概览: (200字以内概括第一卷主线——核心冲突/转折/结尾落点)
（同标准快照逐章/阶段摘要，可酌情扩展至 500 token）

【全量伏笔对账】
— 正常推进 —
V-001｜03｜玉佩符文｜正常推进，距期限尚余X章
V-005｜N｜枯井刻字｜新埋，距期限充裕

— ⚠️ 悬置预警 —
V-002｜07｜老仆失言｜最近呼应仍在第7章，已X章未推进｜
　　建议: 卷2第1-3章安排老仆出场触发

— 建议移交下卷 —
V-001｜顺延至卷2, 期限重设为卷2第8章
V-005｜顺延至卷2, 期限重设为卷2第15章

— 建议本卷回收 —
V-004｜距期限≤2, 本卷末章或卷2首章安排回收

【跨卷移交清单】
跨卷: V-001 移交卷2, 期限顺延为卷2第8章（关联: 苏晚/玉佩/萧家血脉, 需卷2前期铺垫符文规则）
跨卷: V-005 移交卷2, 期限顺延为卷2第15章（关联: 枯井/萧家旧址, 需卷2揭露萧家旧事）
```

### 目标预算与溢出处理（目标 2000 token）

卷末预算为**目标值而非硬上限**。预算按以下优先顺序分配，溢出时按优先级裁剪：

| 优先级 | 内容 | 操作 |
|---|---|---|
| 1（最优先） | 关键事实 / 伏笔内容 / 跨卷移交清单 | **永不压缩** |
| 2 | 伏笔台账（已回收区） | 可精简为"已回收: V-000@5, V-003@10"（仅编号+回收章） |
| 3 | 非关键状态字段 | 去除"当前无变化"的角色状态行 |
| 4（最先压） | 摘要链 | 更早章节合并为阶段摘要，每 10 章一节 |

## 四、通用规则

### 版本号规则

| 快照级别 | 版本号 | 示例 | 跨段规则 |
|---|---|---|---|
| 轻量快照 | 全局递增（每章 +0.1） | v1.1, v1.2, v1.3… v1.14, v2.0 | **跨段不重置**——版本号贯穿全书，便于追溯任意时刻的状态 |
| 标准快照 | 主版本递增（每段 +1.0） | v1.0, v2.0, v3.0… | 独立序列 |
| 卷末快照 | 卷号.0 | v1.0, v2.0, v3.0… | 独立序列 |

轻量快照版本号贯穿全书，与标准/卷末序列互不干扰。示例：第一卷 15 章，轻量快照从 v1.0 一路递增到 v1.14；卷末快照出 v1.0；第二卷首章轻量快照从 v1.15 继续（不重置）。

### 文件命名

| 级别 | 文件名格式 |
|---|---|
| 轻量快照（归档） | `快照/light-v1.12-归档.md` |
| 标准快照 | `快照/standard-v2.0-截至第15章.md` |
| 卷末快照 | `快照/volume-v1.0-第一卷完.md` |
