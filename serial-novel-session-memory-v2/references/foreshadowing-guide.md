# 伏笔管理完整规范 v2.0

---

## 一、全局编号

- 所有伏笔使用唯一编号 `V-001`、`V-002`…，跨章唯一，**永不复用**
- 埋设处：正文或写作备注标注 `【V-00X 埋设】`
- 回收处：正文或写作备注标注 `【V-00X 回收】`
- 呼应/推进但不回收时，在台账更新"最近呼应章"，不改变状态

---

## 二、伏笔日历（deadline 锚点制）

不用模糊区间，用硬期限，避免每章反复判断是否触发：

```
V-001 最迟18章回收(埋3,可提前)   ← 期限前可自由提前回收
V-002 最迟25章回收(埋7,可提前)
V-000 已收@5
```

### 期限规则

| 距期限 | 动作 |
|---|---|
| >2 章 | 正常推进，章前核查时列出可呼应 |
| ≤2 章 | 本章任务**强制标注"⚠️ 临近回收"**，安排铺垫 |
| 到期当章 | **必须回收**，不得顺延 |
| 确需顺延 | 章后对账中标"延后"并写明原因 → 更新日历期限 → 下章强制回收 |

---

## 三、章前核查（写作前）

写本章大纲前，先过一遍台账与日历，输出本章伏笔清单，并入本章任务：

```
【本章伏笔事件】
⚠️ 须回收: V-004（距期限≤2，须在本章或下章安排回收）
须推进: V-001（上次呼应已过3章，本章应有推进）
可呼应: V-002, V-005
```

### 核查步骤

1. 扫描台账「未回收」区 → 列出所有未回收伏笔
2. 按期限排序 → 距期限 ≤2 的标 ⚠️
3. 检查最近呼应章 → 超过 3 章未呼应的标「须推进」
4. 检查是否有到期当章必须回收的 → 标「必须回收」

---

## 四、章后对账（写作后）

章节完成后逐条执行：

### 对账步骤

1. **新埋伏笔** → 登记入账：
   - 分配编号（按序递增，不跳号）
   - 记录：埋设章号 / 内容摘要 / 关联元素（人物/地点/物品/事件） / 期限（最迟第 X 章回收）
   - 期限设定原则：短伏笔 5–10 章内，中伏笔 10–20 章，长伏笔 20–40 章，跨卷伏笔标注"移交卷X"

2. **已回收** → 更新状态：
   - 标记回收章号
   - 移至「已回收」区
   - 伏笔日历对应条目更新为 `V-00X 已收@N`

3. **应推进未推进** → 标"延后"：
   - 台账备注追加「延后: 原因」（如"本章情节未涉及关联人物"）
   - 下章任务自动顺延补上

4. **伏笔变更摘要** → 记入轻量快照：
   - 格式：「新增 V-00X（…）｜ 回收 V-00Y ｜ 推进 V-00Z（呼应章N）」

## 五、台账格式（永不压缩）

```
# 伏笔台账
格式: ID | 埋设章 | 内容/线索 | 关联元素 | 期限(最迟第X章) | 状态 | 最近呼应章

## 未回收
V-001 | 03 | 苏晚袖中半枚玉佩,遇血泛微光,光中隐现符文 | 苏晚/玉佩/萧家血脉 | 最迟18 | 未回收 | 09
V-002 | 07 | 老仆失言:"小姐十岁那年的事,还是别提" | 苏晚/老仆/失忆真相 | 最迟25 | 未回收 | 07
V-004 | 08 | 钱三偷偷烧掉一页账本,灰烬中可见"酉"字 | 钱三/账房/萧母案 | 最迟15 | 未回收⚠️距期限≤2 | 10

## 已回收
V-000 | 01 | 客栈掌柜的算盘缺一颗子 | 掌柜/账本 | 05 | 已回收 | 05
```

### 台账防丢规则

- 台账条目内容**永不删除、永不改写**，只允许更新「状态 / 最近呼应章 / 备注」字段
- 每次段末生成标准快照时，台账随快照写入文件 `快照/standard-vX.X-截至N章.md`
- 双轨环境：快照落盘 = 台账落盘；纯会话环境：提示用户单独保存台账文件

## 六、自动化段末对账（v2.0）

每段末（标准快照 / 卷末快照生成时），AI 自动执行以下对账：

### 悬置预警检测

扫描台账「未回收」区，对满足以下任一条件的伏笔标 ⚠️ 悬置预警：

| 条件 | 判定 |
|---|---|
| 最近呼应章距当前 >5 章 | ⚠️ 悬置——可能被遗忘 |
| 距期限 ≤2 且最近呼应章距当前 >3 章 | ⚠️ 高危——接近期限但长期无推进 |
| 埋设后从未被呼应的伏笔（埋设章 = 最近呼应章），已过 8 章 | ⚠️ 静默伏笔——作者可能忘了 |

### 悬置预警输出格式

```
【伏笔悬置预警·段末自动审查】
⚠️ V-002: 最近呼应仍在第7章，已X章未推进 → 建议: 下段第1-2章安排关联角色出场触发
⚠️ V-006: 埋设后从未呼应（埋于第12章，已过8章） → 建议: 确认是否仍有效; 若废弃请标"作废"
```

### 作者处置选项

AI 列出预警清单后，等待作者逐条指示：

- `回收 V-00X 于下章` → 下章章前核查自动置为"须回收"
- `推进 V-00X 于下段` → 标注优先推进
- `移交 V-00X 至卷X` → 进入跨卷移交清单
- `废弃 V-00X` → 台账标"已废弃"移至独立区，内容不删

## 七、跨卷伏笔继承（v2.0 新增）

### 移交时机

卷末快照生成时，对未回收伏笔逐条判定归属：

| 判定 | 动作 |
|---|---|
| 本卷能回收 | 保留原期限，下卷继续推进 |
| 本卷无法回收（关联元素不在本卷） | 标"移交卷X"，重设期限 |
| 已无回收价值 | 标"建议废弃"，等作者确认 |

### 移交格式

```
【跨卷移交清单 · 第一卷 → 第二卷】
跨卷: V-001 移交卷2, 期限顺延为卷2第8章
　　关联: 苏晚/玉佩/萧家血脉
　　铺垫要求: 卷2前3章需出现"符文"相关线索 → 为新期限铺路
　　理由: 符文体系需卷2引入修炼设定后才能解释

跨卷: V-005 移交卷2, 期限顺延为卷2第15章
　　关联: 枯井/萧家旧址
　　铺垫要求: 卷2第5-8章安排苏晚返回萧家旧址
　　理由: 萧家旧址线索在卷2中段才展开
```

### 期限重置规则

移交跨卷伏笔的期限需满足：

1. **顺延而非悬空**：必须有具体目标章号（卷2第X章），不能只写"移交卷2"
2. **前期铺垫**：新期限不能设为卷2最后几章——应在卷2前 1/3 到 1/2 范围内，确保有足够空间推进
3. **台账同步**：移交时台账状态字段同步更新：
   - 状态：`未回收 → 跨卷(移交卷2,期限顺延为卷2第X章)`
   - 备注：追加「原期限: 卷1第18章」

## 八、全量对账（每 10 章或每 2 个创作段）

执行一次全量对账，不允许静默丢弃任何伏笔：

1. 列出所有未回收伏笔的当前状态与最近呼应章
2. 长期未呼应的标「悬置预警」
3. 列出清单询问作者取舍：提前回收 / 留作后卷 / 废弃
4. 作者确认后 → 台账同步更新，段末快照反映最新状态
